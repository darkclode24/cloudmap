Phase 4 Overview

Compliance, Monitoring & Incident Response

Months 9-10 • Standard compliance frameworks, OpenSCAP auditing, Policy-as-Code (OPA/Rego), cloud-native logging SIEM alert architectures, and Incident Response containment.

Learning Objectives

Read study materials and tick off objectives as you master them:

Compliance Frameworks — Learn CIS Benchmarks, NIST 800-53 controls, SOC 2, HIPAA, and PCI-DSS compliance demands.
Compliance Auditing — Deploy OpenSCAP scanners utilizing XCCDF and OVAL security baselines to audit host safety configuration. OpenSCAP Guides ↗
Policy-as-Code (PaC) — Define cloud architecture compliance and resource access guidelines using Open Policy Agent (OPA) and the Rego policy language. Styra Rego Academy ↗
Cloud Auditing Logs — Configure AWS CloudWatch monitors, CloudTrail tracking records, event triggers, and GuardDuty threat detection.
Centralized SIEM Logging — Deploy ELK stack (Elastic, Logstash, Kibana) or Prometheus/Grafana dashboards to aggregate and visualize system threat indicators.
Incident Response Cycle — Practice live threat triaging, containment scripting playbooks, remediation logs, and post-incident investigation reports.

Capstone Project Journal

Task Scenario: Build a centralized compliance audit engine and alert automation framework combining OpenSCAP, OPA policies, and Slack/Discord webhooks.

[Compliance & SIEM Pipeline Diagram]
Crontab scheduling OpenSCAP checks -> Output security baseline report
├── If OS deviates from CIS Profile -> Trigger alert script
├── OPA policies intercept K8s requests -> Refuse non-least privilege resources
└── AWS GuardDuty finds compromised key -> Pushes high-priority alert to Webhook
