Phase 2 Overview

Cloud Infrastructure & IaC Security

Months 3-5 • Cloud architecture security, Terraform HCL, Ansible hardening, and automated static security checks.

Learning Objectives

Read study materials and tick off objectives as you master them:

AWS Infrastructure — Configure VPC subnets, Security Groups, IAM Policies, CloudTrail logs, and GuardDuty alerts.
Multi-Cloud Mapping — Explore Azure security tools (Entra ID, NSGs, Defender for Cloud) and GCP counterparts.
Infrastructure as Code — Learn provisioning cloud setups using Terraform declarative HCL syntax, modules, and workspaces.
Configuration Hardening — Author secure Ansible playbooks to harden host operating systems, firewalls, and packages. Hardening Framework ↗
IaC Static Analysis — Audit HCL files locally with tools like tfsec and Checkov to identify and block security misconfigurations. Checkov Docs ↗ tfsec Repo ↗
Secrets Vault — Implement cloud secrets isolation utilizing Key Management Services (KMS) and Vault environments. Vault Labs ↗
Least Privilege Design — Formulate IAM policies with granular boundaries, restricting excessive user and resource permissions.
