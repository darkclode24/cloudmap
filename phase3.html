Capstone Project Journal

Task Scenario: Build a complete secure CI/CD pipeline for a containerized web application, implementing shift-left security checks at every milestone.

[Secure CI/CD Pipeline Diagram]
Developer Commit -> Push to GitHub
├── Job 1: SAST (Semgrep code scan)
├── Job 2: SCA (Trivy scans package-lock/npm dependencies)
├── Job 3: Build & Hardened Container Image Scan (Trivy docker scan)
├── Job 4: Deploy & Generate SBOM (Syft tools)
└── Job 5: DAST (OWASP ZAP active scan against live web service)

Requirement Checklist:

GitHub Actions Docker Semgrep Trivy Snyk OWASP ZAP Go Syft
