Phase 3 Overview

CI/CD Pipeline Security & AppSec

Months 6-8 • Secure pipeline creation, container security (Docker), SAST/DAST, SCA dependency checks, and Supply Chain security.

Learning Objectives

Read study materials and tick off objectives as you master them:

CI/CD Workflows — Master automation hooks, secure workflows, and environment secrets management in GitHub Actions or GitLab CI.
Static Code Security — Integrate SAST scans (Semgrep/SonarQube) to identify vulnerabilities, syntax bugs, and insecure programming practices.
Dependency Composition — Audit open-source libraries and transitive dependencies for security vulnerabilities using Snyk or Trivy. Snyk Learn AppSec ↗ Trivy Docs ↗
Docker Hardening — Structure secure multi-stage Dockerfiles utilizing minimal Alpine or Distroless base images and non-root users. Wiz Container Academy ↗
Dynamic Security — Conduct automated DAST runs (OWASP ZAP) against staging web deployments to locate live run-time vulnerabilities. OWASP Juice Shop ↗
Supply Chain Protection — Learn Software Bill of Materials (SBOM) generation (Syft) and binary artifact signing (Cosign).
Go Programming — Grasp baseline Go language syntax, standard library execution, and building lightweight system automation binaries.

Capstone Project Journal

Task Scenario: Build a complete secure CI/CD pipeline for a containerized web application, implementing shift-left security checks at every milestone.

[Secure CI/CD Pipeline Diagram]
Developer Commit -> Push to GitHub
├── Job 1: SAST (Semgrep code scan)
├── Job 2: SCA (Trivy scans package-lock/npm dependencies)
├── Job 3: Build & Hardened Container Image Scan (Trivy docker scan)
├── Job 4: Deploy & Generate SBOM (Syft tools)
└── Job 5: DAST (OWASP ZAP active scan against live web service)
