Phase 1 Overview

Foundations & Security Mindset

Months 1-2 • Foundational Linux, Networking, Scripting, and OWASP Threat awareness.

Learning Objectives

Read study materials and tick off objectives as you master them:

Linux Essentials — Master terminal shell commands, folder/file operations, permission masks (chmod), and command redirection pipelines. LFS101x Intro ↗ Command Line Art ↗
Bash Scripting — Author shell automation scripts executing log parsing hooks, automatic system configurations, and routine file backup pipelines.
Networking Essentials — Understand network protocols TCP/IP routing tables, DNS resolution workflows, HTTP request headers, and secure TLS handshakes.
Python Programming — Learn scripting fundamentals (lists, dictionary mappings, modules) and code basic socket tools for system interaction. AWS Cloud Quest ↗
Git Version Control — Leverage source control branching models (commits, pushes, tags, merges, and pull request collaborations). GitHub Hello-World ↗
Security Mindset — Adopt fundamental methodologies (CIA triad, STRIDE threat models, and OWASP Top 10 vulnerabilities).
Cloud Concepts — Learn the Shared Responsibility model, core compute/storage divisions, cloud console navigation, and secure environments.
